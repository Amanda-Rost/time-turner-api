# ⏳ Time Turner API

API do aplicativo **Time Turner**.

---

## 🚀 Como executar

### 1. Iniciar os serviços

Execute o comando abaixo para iniciar os serviços em segundo plano usando Docker Compose:

```bash
docker compose up -d
```

### 2. Executar a API

Inicie a aplicação Go com o comando:

```bash
go run main.go
```

---

## 🩺 Verificar a aplicação

Para verificar se a API está funcionando, acesse o endpoint de saúde:

**[http://localhost:8080/health](http://localhost:8080/health)**

---

## 🛠️ Tecnologias utilizadas

- **Go** — desenvolvimento da API.
- **Docker Compose** — gerenciamento dos serviços da aplicação.
